# Data

The raw data is **not** included in this repository. This work uses the public
**NCSRD-DS-5GDDoS v2.0** dataset, recorded on a real 3GPP-compliant 5G testbed
(3 cells, 9 UEs, Amarisoft Classic + Mini). Five malicious UEs launch SYN, UDP,
ICMP, DNS and GTP-U flooding attacks while benign UEs stream YouTube/Skype traffic.

Download: https://zenodo.org/records/13900057

Place the extracted CSV files in this folder:

```
data/
  amari_ue_data_classic_tabular.csv
  amari_ue_data_mini_tabular.csv
  amari_ue_data_merged_with_attack_number.csv
  enb_counters_data_classic_tabular.csv
  enb_counters_data_mini_tabular.csv
  mme_counters.csv
  summary_report.xlsx
```

All derived datasets (per-UE datasets, per-attack datasets, input sequences)
are regenerated by the notebooks in `notebooks/01_preprocessing/`, run in
numeric order.
